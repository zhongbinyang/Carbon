# TCB TEC ASCII 独立控温工具设计

日期：2026-07-23
状态：已获用户确认

## 背景与目标

依据《AppNotes TCB系列温控板通信协议 V2.05》的 **标准 ASCII 通信协议**，交付一个**独立 GUI 测试工具**，用于现场设定温度、开关 TEC、读取状态。

背景约束：

- 项目进度中 TEC 的 **Modbus 路径通信异常**；本工具走出厂默认 ASCII，与现有 `tcb_tec.py`（MODBUS）隔离。
- 用户明确要求：**单独工具**、**不共用**现有协议/ToolBox 代码。

## 范围

**本期做：**

- 单文件独立工具：串口收发 + ASCII 组帧/解析 + tkinter GUI
- 串口默认：`9600`、8N1、无校验、无流控；结束符 `\r\n`
- 连接后停自发送：`T0` + `SC`
- 最小命令集（见下）
- 状态显示 + 可选自动刷新 + TX/RX 文本日志
- FakeSerial 单测（不依赖硬件）

**本期不做：**

- MODBUS（`SMS1`、寄存器、CRC）
- PID / 最大占空比 / 偏移量 / 多温度循环等扩展命令
- 接入 Carbon ToolBox / 复用 `tcb_tec.py` / `toolbox.pages.tec_page`
- 打包 exe、UDP

## 通信约定

- 命令与参数之间可有空格；命令字母大小写不敏感，工具统一发大写。
- **严格一问一答**：发出一条命令并收齐以 `\r\n` 结束的响应后，才发下一条。
- 连接成功后依次发送：
  1. `T0` — 停上电自发送（重新上电才持久生效；仍建议每次连接发送）
  2. `SC` — 停止当前自动输出监控数据
- 超时：单条命令等待响应超时则报错，提示检查串口/波特率/板卡是否在线/是否被自发送干扰。

## 命令集

| 功能 | 下发 | 期望响应要点 |
|---|---|---|
| 设温 | `S1{temp}` 如 `S125.2` / `S1-9.5` | `OK` |
| 读当前温度 PV | `RP1` | `P+/-xx.xx` |
| 读设定温度 SV | `RS1` | `S+/-xx.xx` |
| TEC 关闭 | `SEN0` | `TEC Disabled!` |
| TEC 打开 | `SEN1` | `TEC Enabled!` |
| 读 TEC 使能 | `REN` | `0` 或 `1` |
| 读占空比 | `RD` | `D+/-nnn`（千分比，负制冷正加热） |
| 读就绪 | `RR` | `R0` / `R1` |
| 读报警 | `RE` | `En`（n 为报警代码） |
| 停上电自发送 | `T0` | `0` |
| 停当前自发送 | `SC` | `OK` |

“读取状态”一次轮询：`RP1`、`RS1`、`RD`、`RR`、`RE`、`REN`。

## 界面

1. **连接区**：COM 扫描/刷新、波特率（默认 9600）、连接/断开；连接成功执行 `T0`+`SC`
2. **控制区**：目标温度输入、设定温度、TEC 开、TEC 关、读取状态、自动刷新（可选）
3. **状态区**：PV、SV、占空比、就绪、报警、TEC 使能
4. **日志区**：TX/RX 原始文本行

读写在后台线程执行；未连接时禁用操作按钮；关闭窗口时断开串口。

## 错误处理

- 参数：温度非数字、空命令等 → 弹窗
- 超时 / 响应不含期望前缀或关键字 → 明确报错并记入日志
- 报警代码：原样显示 `En`；若文档有常用码表可在日志旁注，不强制完整映射表

## 测试

- 单测：命令拼装、响应解析（`RP1`/`RS1`/`RD`/`RR`/`RE`/`REN`/`SEN*`/`S1`）、一问一答收发路径（FakeSerial）
- 联调：真实 COM3/COM4 由人工验证

## 成功标准

- 单独启动窗口，连上温控板后可：设温、开关 TEC、读出 PV/SV/占空比/就绪/报警
- 日志可见完整 ASCII 收发行
- 仅依赖 `pyserial` + 标准库 tkinter；不依赖现有 Modbus/ToolBox 模块
